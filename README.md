# AIrobot · 로봇팔 AI 융합 실습 웹앱

이 저장소는 EEZYbotARM Mk2 + Arduino UNO R3 + PCA9685 기반의 **학생용 시뮬레이터 / 선택적 실물 조작** 프로젝트입니다.

- 시뮬레이터: Netlify 접속 후 별도 장비 없이 실행
- 수동 실물 조작: HTTPS에서 Chrome/Edge Web Serial로 본인 PC에 USB로 연결된 Arduino 사용
- AI 채팅: Netlify Functions와 OpenAI 호환 LLM API를 연결해 한국어 명령을 구조화 (별도 API 키 필요)
- 카메라: 학습된 이미지 모델을 추가하면 A·B·C 위치의 표식 추론에 사용
- 실제 집기: 개인 장치의 서보 방향/안전 범위/각 위치를 **현장에서 보정**해야 함

> **안전:** 현재 GitHub 저장소에 코드가 있다고 실제 장비에서 검증된 것은 아닙니다. 소프트웨어 정지는 비상 전원 차단 장치가 아닙니다. 실험 중 손·물체를 작동 범위에서 멀리하고 교사 감독하에 무부하로 축별 점검하십시오.

구체적인 배포·장비 연결 방법은 아래 추가 문서와 애플리케이션의 ‘설치 안내’를 참고하세요.
